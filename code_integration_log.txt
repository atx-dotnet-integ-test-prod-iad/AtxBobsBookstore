CHANGE 4: SelectAuthorsByHireYear Method
================================================================================
File: app/Bookstore.Web/Controllers/AuthorsController.cs
Method: SelectAuthorsByHireYear
Line Number: ~217
Statement ID: 4

Original SQL Server Statement:
SELECT BusinessEntityID, FORMAT(ModifiedDate, 'yyyy-MM-dd HH:mm:ss') AS FormattedModifiedDate, DATEDIFF(YEAR, BirthDate, GETDATE()) AS Age FROM bobsbookstore_dbo.author WHERE DATEPART(YEAR, HireDate) = @HireDate;

Converted PostgreSQL Statement:
SELECT BusinessEntityID, TO_CHAR(ModifiedDate, 'YYYY-MM-DD HH24:MI:SS') AS FormattedModifiedDate, EXTRACT(YEAR FROM AGE(CURRENT_TIMESTAMP, BirthDate)) AS Age FROM bobsbookstore_dbo.author WHERE EXTRACT(YEAR FROM HireDate) = @HireDate;

Conversion Type: T-SQL Date/Time Functions → PostgreSQL Equivalents
Conversion Method: MANUAL_AFTER_DMS_FAILURE
Schema Changes: None (already using bobsbookstore_dbo.author)

Key Changes Made:

1. FORMAT Function Conversion:
   - Original: FORMAT(ModifiedDate, 'yyyy-MM-dd HH:mm:ss')
   - Converted: TO_CHAR(ModifiedDate, 'YYYY-MM-DD HH24:MI:SS')
   - Notes: PostgreSQL uses different format codes
     * YYYY for 4-digit year (was yyyy)
     * MM for month (same)
     * DD for day (same)
     * HH24 for 24-hour format (was HH)
     * MI for minutes (was mm)
     * SS for seconds (was ss)

2. DATEDIFF Function Conversion:
   - Original: DATEDIFF(YEAR, BirthDate, GETDATE())
   - Converted: EXTRACT(YEAR FROM AGE(CURRENT_TIMESTAMP, BirthDate))
   - Notes: 
     * AGE(date2, date1) calculates interval between dates
     * EXTRACT(YEAR FROM interval) gets year component
     * CURRENT_TIMESTAMP replaces GETDATE()

3. DATEPART Function Conversion:
   - Original: DATEPART(YEAR, HireDate)
   - Converted: EXTRACT(YEAR FROM HireDate)
   - Notes: EXTRACT directly gets date parts in PostgreSQL

4. GETDATE Function Conversion:
   - Original: GETDATE()
   - Converted: CURRENT_TIMESTAMP
   - Notes: PostgreSQL standard function for current timestamp

Code Context:
- Method signature unchanged
- Return type unchanged (async Task<List<AuthorAgeResult>>)
- Error handling preserved
- Parameter binding preserved (NpgsqlParameter for @HireDate)
- Column aliases unchanged (FormattedModifiedDate, Age)

Manual Adjustments: None required beyond conversion

Notes:
- Date format conversions need manual testing to verify identical output
- Age calculation may have subtle differences in leap year handling
- Recommended to test with sample data covering edge cases
