CHANGE 4: SelectAuthorsByHireYear Method
================================================================================
File: app/Bookstore.Web/Controllers/AuthorsController.cs
Method: SelectAuthorsByHireYear
Line: 228

Original MS SQL Server Statement:
----------------------------------
SELECT BusinessEntityID, FORMAT(ModifiedDate, 'yyyy-MM-dd HH:mm:ss') AS FormattedModifiedDate, DATEDIFF(YEAR, BirthDate, GETDATE()) AS Age FROM bobsbookstore_dbo.author WHERE DATEPART(YEAR, HireDate) = @HireDate;

Converted PostgreSQL Statement:
--------------------------------
SELECT businessentityid, TO_CHAR(modifieddate, 'YYYY-MM-DD HH24:MI:SS') AS formattedmodifieddate, DATE_PART('year', AGE(CURRENT_TIMESTAMP, birthdate))::INTEGER AS age FROM bobsbookstore_dbo.author WHERE EXTRACT(YEAR FROM hiredate) = @HireDate;

Changes Applied:
----------------
1. Column Name Case Changes (PostgreSQL lowercase convention):
   - BusinessEntityID → businessentityid
   - ModifiedDate → modifieddate
   - BirthDate → birthdate
   - HireDate → hiredate

2. Date Formatting Function:
   - FORMAT(ModifiedDate, 'yyyy-MM-dd HH:mm:ss') → TO_CHAR(modifieddate, 'YYYY-MM-DD HH24:MI:SS')
   - Changed function name from FORMAT to TO_CHAR
   - Updated format pattern to PostgreSQL style:
     * yyyy → YYYY
     * HH:mm:ss → HH24:MI:SS

3. Alias Case Change:
   - FormattedModifiedDate → formattedmodifieddate (PostgreSQL lowercase convention)

4. Age Calculation:
   - DATEDIFF(YEAR, BirthDate, GETDATE()) → DATE_PART('year', AGE(CURRENT_TIMESTAMP, birthdate))::INTEGER
   - GETDATE() → CURRENT_TIMESTAMP (PostgreSQL current timestamp function)
   - DATEDIFF(YEAR, date1, date2) → AGE(date2, date1) (PostgreSQL interval calculation)
   - Added DATE_PART('year', ...) to extract year component from interval
   - Added ::INTEGER cast to ensure integer return type

5. Alias Case Change:
   - Age → age (PostgreSQL lowercase convention)

6. Date Part Extraction in WHERE Clause:
   - DATEPART(YEAR, HireDate) → EXTRACT(YEAR FROM hiredate)
   - Changed function from DATEPART to EXTRACT (PostgreSQL standard SQL function)
   - Changed syntax from DATEPART(unit, date) to EXTRACT(unit FROM date)

Parameter Bindings: PRESERVED
- @HireDate (int)

Return Type: PRESERVED
- Returns List<AuthorAgeResult>
- AuthorAgeResult properties:
  * BusinessEntityID (int) - now populated from businessentityid
  * FormattedModifiedDate (string) - now populated from formattedmodifieddate
  * Age (int) - now populated from age

Error Handling: PRESERVED
- try-catch block maintained

Note: Column name case changes match PostgreSQL schema definition where columns
      are typically lowercase. The .NET entity mapping handles case-insensitive
      property binding automatically.
