Check that any APIs used in the project are supported on the target platform. Pay particular attention to:

- File path handling (`Path.Combine` vs hardcoded separators)
- Registry access (not available on Linux/macOS)
- Windows-specific authentication or identity APIs

## 6. Validate the Web Layer

```bash
dotnet run --project Bookstore.Web --configuration Release
```

Check the following:

- All routes resolve correctly.

- Authentication and authorization middleware, if used, is configured correctly for ASP.NET Core.
- Any configuration previously in `Web.config` has been moved to `appsettings.json` and is being read via `IConfiguration`.

Confirm that settings previously stored in `Web.config` or `App.config` have been fully migrated to the `appsettings.json` pattern. Check for:

---

## 8. Publish the Application

Once validation is complete, publish the application to a target folder:

```bash
dotnet publish Bookstore.Web --configuration Release --output ./publish
```

Review the output directory to confirm all required files are present, then deploy the contents to the target hosting environment (IIS, a Linux server, or Azure App Service).

For IIS hosting, ensure the **ASP.NET Core Hosting Bundle** is installed on the server and that the `web.config` generated by the publish process is present and correctly configured.
