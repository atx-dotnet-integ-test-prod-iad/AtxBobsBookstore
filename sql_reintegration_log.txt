STATEMENT 4: SelectAuthorsByHireYear
------------------------------------------------------------------------
Method: SelectAuthorsByHireYear(int hireYear)
Approximate Line Number: 210-223 (method body)
Status: UPDATED

ORIGINAL SQL (SQL Server):
SELECT BusinessEntityID, FORMAT(ModifiedDate, 'yyyy-MM-dd HH:mm:ss') AS FormattedModifiedDate, DATEDIFF(YEAR, BirthDate, GETDATE()) AS Age FROM bobsbookstore_dbo.author WHERE DATEPART(YEAR, HireDate) = @HireDate;

CONVERTED SQL (PostgreSQL):
SELECT BusinessEntityID, TO_CHAR(ModifiedDate, 'YYYY-MM-DD HH24:MI:SS') AS FormattedModifiedDate, EXTRACT(YEAR FROM AGE(CURRENT_TIMESTAMP, BirthDate)) AS Age FROM bobsbookstore_dbo.author WHERE EXTRACT(YEAR FROM HireDate) = @HireDate;

SCHEMA MAPPINGS:
- No schema changes (bobsbookstore_dbo preserved)
- Schema name remains: bobsbookstore_dbo.author

FUNCTION TRANSFORMATIONS:
1. FORMAT(ModifiedDate, 'yyyy-MM-dd HH:mm:ss') 
   → TO_CHAR(ModifiedDate, 'YYYY-MM-DD HH24:MI:SS')
   - Changed function name: FORMAT → TO_CHAR
   - Updated format string: 'yyyy-MM-dd HH:mm:ss' → 'YYYY-MM-DD HH24:MI:SS'
   - PostgreSQL uses uppercase YYYY and HH24 for 24-hour format

2. DATEDIFF(YEAR, BirthDate, GETDATE()) 
   → EXTRACT(YEAR FROM AGE(CURRENT_TIMESTAMP, BirthDate))
   - SQL Server DATEDIFF calculates difference in specified unit
   - PostgreSQL AGE() returns interval between dates
   - EXTRACT gets the year component from the interval

3. DATEPART(YEAR, HireDate) 
   → EXTRACT(YEAR FROM HireDate)
   - SQL Server DATEPART extracts date parts
   - PostgreSQL EXTRACT performs same operation

4. GETDATE() 
   → CURRENT_TIMESTAMP
   - SQL Server GETDATE() returns current datetime
   - PostgreSQL CURRENT_TIMESTAMP is standard SQL equivalent

- Parameter name: @HireDate
- Parameter syntax preserved (Npgsql compatible)
